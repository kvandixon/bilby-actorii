## 1. Pre-Flight & Runtime Contract

Both adapters enforce the following benchmark-container defaults (lazy-initialized on task execution, never at import time):
- `ACTORII_HOST_LOCKDOWN=0` (safe inside ephemeral Docker task sandboxes; **never** unset host lockdown on bare-metal `valkyrie`)
- `ACTORII_BENCH_STRICT=1` (disables production host shortcuts and demo twins)
- `ACTORII_DISABLE_DEMO_TWINS=1`
- `ACTORII_LLM_ENDPOINT` & `ACTORII_LLM_MODEL` injected via environment variables or CLI flags (no hardcoded secrets or local `:8080` assumptions in published images)

## 3. AgentBeats (`agentbeats.dev` — Berkeley RDI Purple Agent)

### 3.1 Build `linux/amd64` Purple-Agent Docker Image
AgentBeats requires reproducible `linux/amd64` Docker images pushed to a public registry (e.g., GHCR) that start cleanly without local-only host mounts and honor `--host`, `--port`, and `--card-url`.

Example `Dockerfile.agentbeats` (built from `/home/skippy/projects/ActorII`):
```dockerfile
FROM python:3.11-slim

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PYTHONPATH=/app/src:/app \
    ACTORII_IN_DOCKER=1 \
    ACTORII_HOST_LOCKDOWN=0 \
    ACTORII_BENCH_STRICT=1 \
    ACTORII_DISABLE_DEMO_TWINS=1

WORKDIR /app
RUN apt-get update && apt-get install -y --no-install-recommends git ca-certificates && rm -rf /var/lib/apt/lists/* && \
    pip install --no-cache-dir websockets clingo networkx pyyaml

COPY pyproject.toml /app/
COPY src /app/src
COPY deploy/arena_adapters/agentbeats_purple_agent.py /app/deploy/arena_adapters/agentbeats_purple_agent.py

RUN useradd -u 10001 -m -s /bin/bash bilby && mkdir -p /workspace && chown -R bilby:bilby /workspace /app
USER bilby
EXPOSE 9009

ENTRYPOINT ["python3", "/app/deploy/arena_adapters/agentbeats_purple_agent.py"]
CMD ["--host", "0.0.0.0", "--port", "9009"]
```

Build and push `linux/amd64`:
```bash
cd /home/skippy/projects/ActorII
docker buildx build \
  --platform linux/amd64 \
  -f Dockerfile.agentbeats \
  -t ghcr.io/<org>/bilby-actorii-purple:4.4.0 \
  --push .
```

### 3.2 Local Validation (A2A Contract Smoke Test)
Start the container (or run locally) and verify discovery + health + JSON-RPC endpoints:

```bash
docker run --rm -p 9009:9009 \
  -e ACTORII_LLM_ENDPOINT="https://<provider>/v1/chat/completions" \
  -e ACTORII_LLM_MODEL="<model>" \
  -e OPENAI_API_KEY="${OPENAI_API_KEY:-}" \
  ghcr.io/<org>/bilby-actorii-purple:4.4.0 \
  --host 0.0.0.0 --port 9009 --card-url http://127.0.0.1:9009

# 1. Health check (zero LLM calls)
curl -sf http://127.0.0.1:9009/health | jq .

# 2. A2A Agent Card discovery (both paths supported)
curl -sf http://127.0.0.1:9009/.well-known/agent.json | jq .
curl -sf http://127.0.0.1:9009/.well-known/agent-card.json | jq .

# 3. A2A JSON-RPC 2.0 `message/send`
curl -sf -X POST http://127.0.0.1:9009/ \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": "smoke-1",
    "method": "message/send",
    "params": {
      "message": {
        "role": "user",
        "parts": [{"kind": "text", "text": "Reply with OK and the sum of 2 + 2."}]
      }
    }
  }' | jq .
```

### 3.3 Public Registration & Submission on `agentbeats.dev`
1. Ensure the GHCR image `ghcr.io/<org>/bilby-actorii-purple:4.4.0` has **Public** package visibility.
2. Sign in to `https://agentbeats.dev` and register a new **Purple Agent**:
   - **Image URI**: `ghcr.io/<org>/bilby-actorii-purple:4.4.0`
   - **Port**: `9009`
   - **Agent Card Path**: `/.well-known/agent.json` (also serves `/.well-known/agent-card.json`)
   - **Required Secrets / Env Vars**: `ACTORII_LLM_ENDPOINT`, `ACTORII_LLM_MODEL`, and provider API key if using a hosted LLM.
3. Trigger a validation assessment against a target **Green Agent** (e.g., SWE-bench, Terminal-Bench, or domain arena green agent) via the AgentBeats portal or competition GitHub Actions workflow.
4. Confirm the assessment completes cleanly and publish the verified run to the public AgentBeats leaderboard.
