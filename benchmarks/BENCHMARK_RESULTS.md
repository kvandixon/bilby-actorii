# Bilby (`ActorII v4.1`) — Master Head-to-Head Benchmark Results Grid

## Benchmark Integrity & Head-to-Head Rules

1. **Only Bilby Is Tested Locally on `valkyrie`**:
   - **Bilby (`ActorII v4.1` + Neo4j `:ActorEpisode`/`:ActorEngram` graph memory)** is the only agent harness we test on our local `valkyrie` hardware (`RTX 5070 Ti 16 GB VRAM`, `qwen3.8-27b` on `:8080`).
   - All other columns (**Hindsight**, etc.) report **only their official published benchmark results** directly from their upstream benchmark repositories and leaderboards (e.g., [`benchmarks.hindsight.vectorize.io`](https://benchmarks.hindsight.vectorize.io) and [`vectorize-io/agent-memory-benchmark`](https://github.com/vectorize-io/agent-memory-benchmark)). We never recreate or re-run other harnesses locally to fill their columns.
2. **Exact Question Set & Instruction Parity (`N = N`)**:
   - To compare `%` accuracy honestly, every harness in a row must be evaluated on the **exact same benchmark dataset and question count (`N`)**.
   - If a published run drops a category (for example, Hindsight's `LoCoMo` `1,540`-question run excludes the `446` Category-5 adversarial abstention questions from the full `1,986`-question `LoCoMo-10` dataset), we score Bilby on the **exact same `1,540` questions** (`cat1`–`cat4`: `1,168 / 1,540 = 75.84%`) in that row, and list the full `1,986`-question `LoCoMo-10` dataset (`1,536 / 1,986 = 77.34%`) in its own separate row.
3. **Zero Mid-Run Intervention**:
   - Only clean, hands-off benchmark runs of Bilby are posted to this grid. Diagnostic ("test-and-repair") runs are kept in [`benchmarks/archive/`](archive/).
