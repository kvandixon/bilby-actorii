# Bilby (`ActorII v4.1`) — Master Head-to-Head Benchmark Results Grid

## Benchmark Integrity & Head-to-Head Rules

1. **Identical Question Sets & Instructions (`N = N`)**:
   - Every harness compared in a row of the Master Grid must be evaluated against the **exact same question set (`N` tasks)**, the **exact same task instructions**, and the **exact same grading rubric**.
   - A run on a subset (e.g., 11 minimum-acceptance cases) is **never** compared in the same row against a run on a different question count (e.g., 42 full cases). Each row locks the exact question count (`N`) and commit/dataset version.
2. **Independent, Zero-Intervention Runs Only**:
   - Only truly independent, hands-off benchmark runs are recorded in this grid.
   - Diagnostic ("test-and-repair") runs used to debug harness plumbing or timeouts are stored separately in [`benchmarks/archive/`](archive/) and never posted as official scores.
3. **Do Not Test Other Models/Agents Unless Directed**:
   - Future columns are reserved for when we explicitly run another harness against the exact same question set (`N` tasks). Until a harness is independently evaluated on that exact question set, its cell remains `— (Not yet run on this exact question set)`.
